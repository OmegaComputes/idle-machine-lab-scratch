## What pupils do

These notes are inside the starter, as yellow comments next to the code:

**Pia**

> TODO 1: Ask "Who gets?" and set [getter] to the answer.
>
> TODO 2: Ask "How many counters?" and set [how many] to the answer.
>
> TODO 3: Use "add [ ] to [ledger]" with "join" blocks, so a line reads: Line 1: Ana gives 2 to Ben
>
> TODO 4: Say how many lines the ledger has, using "length of [ledger]".

## How to check it works

Click Pia. Type **Ana**, **Ben**, **2**. The ledger should show **Line 1: Ana gives 2 to Ben**.

The same check runs automatically in `tests/validate.js`.
