# Security

## Reporting a problem

Email **hello@omegacompute.com** with the subject `idle-machine-lab security`. Say what you found, which file or commit, and how to
reproduce it. Do not open a public issue for a security or child-safety problem.

We will acknowledge your report and keep you updated. Please give us a reasonable time to fix it before you
disclose it.

## What is in scope

- Bugs in the build tools, the validator or the CI workflow.
- Anything in a project or doc that could expose a child's personal data, or that sends pupils to a sign-up, link or contact.
- A project file that loads something from outside the .sb3.

## Handling secrets and personal data

- Never put a real password, token, private key, wallet seed or personal detail into an issue, a pull request, a
  log, a test or a project file. Examples use made-up values only.
- Never add pupil names, photos, voices or work to this repository.
